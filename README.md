## 📋 ToList

O ToList é um aplicativo mobile de gerenciamento de tarefas desenvolvido com React Native + Expo utilizando banco de dados local com SQLite. O objetivo do app é ajudar o usuário a organizar sua rotina de forma simples, prática e intuitiva.

## Funcionalidades

✅ Cadastro de tarefas  
✅ Listagem de tarefas  
✅ Edição de tarefas  
✅ Exclusão de tarefas  
✅ Marcar tarefas como concluídas  
✅ Armazenamento local com SQLite  
✅ Interface moderna e organizada  
✅ Navegação com Drawer Navigator  

## Tecnologias utilizadas

- React Native
- Expo
- Expo Go
- SQLite
- React Navigation
- JavaScript

## Como executar o projeto

1. Clone o repositório
2. Instale as dependências: **npm install**
3. Execute o projeto: **npx expo start**
4. Instale o aplicativo Expo Go e Escaneie o QR Code exibido no terminal/navegador
- Android: *https://play.google.com/store/apps/details?id=host.exp.exponent*
- iOS: *https://apps.apple.com/app/expo-go/id982107779*

## Observações
O projeto foi desenvolvido para execução mobile utilizando o Expo Go. <br>
O banco SQLite funciona localmente no dispositivo.<br>
O projeto pode apresentar limitações na versão Web.
